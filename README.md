# Data Science & Business Analytics Portfolio

Project notebooks from the **Post Graduate Program in Data Science and Business Analytics** at the University of Texas at Austin (McCombs School of Business, with Great Learning), 2024–2025.

Each project starts from a real-world business question, explores the data, and ends with a recommendation for the business. The notebooks are in Python (pandas, scikit-learn, statsmodels, seaborn) and run in Google Colab. Click the "Open in Colab" badge at the top of any notebook to run it.

## Projects

| # | Module | Project | Business question | Techniques |
|---|--------|---------|-------------------|------------|
| 1 | Python Foundations | [FoodHub](01-python-foundations-foodhub/) | What drives demand and customer experience for a food-delivery aggregator? | Exploratory data analysis, visualization |
| 2 | Business Statistics | [E-news Express](02-business-statistics-enews-express/) | Does a redesigned landing page convert more subscribers? | A/B testing, hypothesis testing |
| 3 | Supervised Learning – Foundations | [ReCell](03-supervised-learning-recell/) | What should a used or refurbished phone sell for? | Linear regression, model assumptions |
| 4 | Supervised Learning – Classification | [INN Hotels](04-classification-inn-hotels/) | Which hotel bookings are likely to be canceled? | Logistic regression, decision trees |
| 5 | Ensemble Techniques | [EasyVisa](05-ensemble-techniques-easyvisa/) | Which work-visa applications are likely to be approved? | Bagging, random forest, boosting |
| 6 | Model Tuning | [ReneWind](06-model-tuning-renewind/) | Can we predict wind-turbine failures before they happen? | Hyperparameter tuning, over- and under-sampling, pipelines |
| 7 | Unsupervised Learning | [Trade & Ahead](07-unsupervised-learning-trade-and-ahead/) | How can stocks be grouped for portfolio recommendations? | K-means and hierarchical clustering |

The [practice exercises](practice-exercises/) folder holds smaller exercises on estimation, hypothesis testing and linear-regression assumptions.
